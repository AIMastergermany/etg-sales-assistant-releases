# ETG Sales Assistant – Downloads und Auto-Update

Hier liegen die fertigen Fassungen der Desktop-App **ETG Sales Assistant** (Add-on für ETG ChatterHub).
Die App holt sich ihre Updates von dieser Seite.

- macOS (Apple Silicon): `ETG-Sales-Assistant-mac-arm64.dmg`
- Windows (64 Bit): `ETG-Sales-Assistant-<Version>-win-x64-Setup.exe`

Die Fassungen stehen unter „Releases“. Herausgeber: Andreas Scheffels (EasyToGrow).
